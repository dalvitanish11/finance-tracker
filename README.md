# Finance tracker

Responsive finance tracker built with React, Vite, JavaScript, HTML and CSS.

## Run

    npm install
    npm run dev

## Features

- Add, edit and delete income and expense transactions
- Live balance, income and expense totals with a spent-vs-income bar
- Filter by all, income or expenses
- Data saved in the browser (localStorage)
- Reusable components: Button, Stat, Summary, TransactionForm, TransactionList, TransactionItem

Currency is set in `src/utils/format.js` (default ₹ INR).
